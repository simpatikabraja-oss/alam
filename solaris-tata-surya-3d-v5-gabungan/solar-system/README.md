# Solaris V5 — Simulasi Tata Surya 3D

Solaris adalah simulasi tata surya berbasis Canvas yang dapat dibuka langsung dari `index.html` setelah ZIP diekstrak.

## Fitur V3
- Orbit planet yang terlihat dan dapat diaktif/nonaktifkan.
- Tampilan planet dengan artwork lokal resolusi tinggi.
- Detail visual: kawah, atmosfer, awan Bumi, pita gas, dan badai Jupiter.
- Planet dapat dipilih untuk fokus kamera dan membuka informasi.
- Galeri planet menggunakan gambar lokal yang sama dengan tampilan utama.
- Timeline/speed simulation.
- Sistem satelit sederhana.
- Mission Mode dan Mode Edukasi.
- Menu Tentang Saya — Braja Simpatka.
- Tidak membutuhkan server lokal atau internet.

## Menjalankan
1. Ekstrak seluruh ZIP.
2. Masuk ke folder `solar-system`.
3. Buka `index.html` dengan Chrome/Edge.

Semua aset penting disimpan di `assets/planets/` dan harus tetap berada di dalam folder proyek.


## Solaris V5 — Gabungan V1–V5
- Klik planet langsung melakukan camera focus ke planet yang dipilih.
- Kamera mengikuti planet selama simulasi berjalan; tombol FOLLOW/FREE tersedia.
- Klik area kosong pada canvas untuk menutup deskripsi planet tanpa mengganggu fokus kamera.
- Panel info planet memiliki tab Info, Satelit, Atmosfer, dan Fakta.
- Timeline tanggal bisa digeser manual; speed simulation sampai x10000.
- Mission Mode menampilkan lintasan transfer dan spacecraft sederhana.
- Education Mode memiliki scale mode dan mini quiz.
- Orbit, asteroid belt, moon system, minimap, compass, audio cue, fullscreen, gallery, settings, dan profil Braja Simpatka tetap dipertahankan.
