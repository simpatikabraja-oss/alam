Solaris V3 — Changelog

- Enhanced local planet textures: Sun, Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune.
- Added atmospheric shading, surface detail, cloud patterns, crater fields, gas-giant bands, and Jupiter storm detail.
- Planet thumbnails/gallery now use local high-resolution assets.
- Planet info cards use the same local planet artwork.
- Added Mission Mode and Education panel to match the Solaris V3 mockup direction.
- Kept the project fully offline: no CDN, no Three.js, no external font, no external asset dependency.
- Added local texture preloading without blocking the first Canvas frame.
